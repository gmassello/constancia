# Hackathon — rules and criteria

Source: <https://lablab.ai/ai-hackathons/assemblyai-voice-agent-hackathon> (transcribed 2026-09-02).

## Window

1–30 Sep 2026. Closes **30 Sep 2026, 12:00 ART**. Registration stays open for the whole window.

## Team

1 to 6 people. Solo is allowed: a team of one on the platform plus registration on the Discord.

## Prize

5 winners, no ranking: US$1,000 cash + US$1,000 in AssemblyAI credits each.

## Technical paths

| Path | What it is | Cost | Ours |
|---|---|---|---|
| A — Voice Agent API | All-in-one: STT + LLM + TTS + turn-taking + tool calling | ~US$4.50/hour, free-tier status unconfirmed | No |
| B — Realtime Speech-to-Text | STT only; we build LLM and TTS | ~US$0.15/hour, **333 free hours** | **Yes** |

## Mandatory deliverables

- [ ] Public GitHub repo with MIT license
- [ ] Demo video, 5 minutes maximum
- [ ] Deck / slide presentation
- [ ] Deployed app with a public URL

## Judging criteria

No published weights; assume 25% each.

| Criterion | What it asks |
|---|---|
| Application of Technology | How well the technology is used, AssemblyAI in particular |
| Presentation | How clearly the project is shown and explained |
| Business Value | Whether it solves a real problem for someone who would pay |
| Originality | Whether it does something nobody else is doing |

See `SUBMISSION.md` for how each one is covered and where the judge sees it.
